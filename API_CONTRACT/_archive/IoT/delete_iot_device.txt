7-5 IoTデバイスの登録解除 (Deregister IoT Device) 

DELETE /iot-devices/{deviceId}
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: application/json

Request Body (JSON):
{
  "memberId": "member-123",
  "deviceId": "dev-001",
  "forceDelete": false
}

Response - Success (HTTP 200)
{
  "deviceId": "dev-001",
  "memberId": "member-123",
  "status": "DELETED",
  "iotCoreThingName": "member-123-dev-001",
  "deletedAt": "2025-04-08T10:00:00Z"
}

Response - Error (HTTP 400)
{
  "statusCode": "VALIDATION_ERROR",
  "message": "入力内容に不備があります。",
  "fields": {
    "memberId": "memberId は必須項目です。",
    "deviceId": "deviceId は必須項目です。"
  }
}

Response - Error (HTTP 401)
{
  "statusCode": "UNAUTHORIZED",
  "message": "認証に失敗しました。再度ログインしてください。"
}

Response - Error (HTTP 403)
{
  "statusCode": "FORBIDDEN",
  "message": "この会員のIoTデバイスを削除する権限がありません。"
}

Response - Error (HTTP 404)
{
  "statusCode": "DEVICE_NOT_FOUND",
  "message": "指定されたデバイスが見つかりません。memberId と deviceId を確認してください。"
}

Response - Error (HTTP 409)
{
  "statusCode": "DEVICE_DELETE_CONFLICT",
  "message": "デバイスが使用中のため削除できません。forceDelete を指定して再実行してください。"
}

Response - Error (HTTP 500)
{
  "statusCode": "SERVER_ERROR",
  "message": "サーバ内部でエラーが発生しました。時間をおいて再度お試しください。"
}

Response - Error (HTTP 502)
{
  "statusCode": "IOT_CORE_ERROR",
  "message": "IoT Core との連携中にエラーが発生しました。時間をおいて再度お試しください。"
