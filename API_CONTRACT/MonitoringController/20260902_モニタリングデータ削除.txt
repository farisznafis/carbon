//モニタリングデータの削除。運営者専用（admin または権限を持つ operator）。
//
//【重要】これは物理削除（削除）であり、取消ではない。削除されたデータは復元できない。
//モニタリングの取消申請とは別機能。取消は /api/monitoring/cancel-requests を参照。
//
//【2026-10-01 変更】削除は手動実行から自動実行に変更した。
//  廃止: GET  /api/admin/monitoring-data/deletion-candidates
//  廃止: GET  /api/admin/monitoring-data/deletion-candidates/{projectPublicId}
//  廃止: POST /api/admin/monitoring-data/deletion
//  追加: GET  /api/admin/monitoring-data/deletion-schedule
//  継続: GET  /api/admin/monitoring-data/deletion-history（変更なし）
//
//削除対象は、プロジェクトのステータスが「終了」になってから保存期間が経過したプロジェクトの
//モニタリングデータすべて。プロジェクト単位で削除し、拠点・企業・レコードの選択はできない。
//保持年数は app.monitoring.retention.retention-years で設定（現在: 2年）。
//
//自動削除の流れ（1日1回のバッチ。既定は毎日 02:00）:
//  1. 削除予定日の7日前 : 運営ユーザー全員に「モニタリングデータ削除予定のお知らせ」を通知
//  2. 削除予定日の当日  : 「モニタリングデータ削除開始のお知らせ」を通知し、削除を開始
//  3. 全件削除の完了時  : プロジェクトごとに「モニタリングデータ削除完了のお知らせ」を通知
//  通知はアプリ内通知とメールの両方。1・2 は同じ日に該当するプロジェクトを1通にまとめる。
//  削除できなかったレコードは次回以降のバッチで自動的に再実行される。
//
//必要権限:
//  削除予定・履歴 : admin、または MONITORING_READ を持つ operator


■ 削除予定取得（プロジェクト単位）

GET /api/admin/monitoring-data/deletion-schedule
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Response - Success (HTTP 200)
{
  "statusCode": "OK",
  "message": "モニタリングデータの削除予定を取得しました。",
  "autoDeletionEnabled": true,          //false の環境では自動削除バッチは動かない
  "totalProjects": 1,
  "schedule": [                         //削除予定日の近い順
    {
      "projectId": 1,
      "projectPublicId": "PRJ00000001",
      "projectName": "ABC太陽光発電プロジェクト",
      "statusFinalizedAt": "2024-10-08T10:30:00",   //ステータスが「終了」になった日時
      "scheduledDeletionDate": "2026-10-08",
      "daysUntilDeletion": 7                        //0 は本日削除
    }
  ]
}

//削除予定日が本日以降のプロジェクトのみ返す。削除予定日を過ぎたプロジェクトは削除履歴で確認する。
//該当するプロジェクトがない場合も HTTP 200。totalProjects は 0、schedule は空配列。


■ 削除履歴取得

GET /api/admin/monitoring-data/deletion-history?projectId=1&page=1&limit=20
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

//projectId : 任意。指定しない場合は全プロジェクトが対象
//page      : 任意。既定値 1、1以上
//limit     : 任意。既定値 20、1〜100

Response - Success (HTTP 200)
{
  "statusCode": "OK",
  "history": [
    {
      "id": 501,
      "monitoringRecordId": "SITEa8Kd93jFnQ2xLp0w#PRJ00000001",
      "recordTimeUpdated": "2023-04-01T09:15:00",
      "dateRecorded": "2023-04-01",
      "projectId": 1,
      "siteId": 3,
      "result": "SUCCESS",              //SUCCESS または FAILURE
      "failureReason": null,            //FAILURE のときのみ内容が入る
      "deletedAt": "2026-10-08T02:00:12",
      "deletedBy": "system"             //自動削除は "system"。過去の手動削除分は実行した運営ユーザー名
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "totalItems": 1250,
    "totalPages": 63,
    "hasMore": true
  }
}

//削除したレコードは1件ずつ削除履歴に記録される。
//FAILURE のレコードは次回のバッチで再実行され、削除できた時点で SUCCESS の行が追加される。
