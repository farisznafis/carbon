■ ページ取得

GET /api/projectplan/{projectId}/forms/{formSlug}?methodology=2
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

//methodology は任意。方法論によって項目が変わるページでのみ指定する。

Response - Success (HTTP 200)
{
  "statusCode": "OK",
  "formSlug": "additional-assessment-method",
  "displayName": "追加性の評価方法",
  "status": "COMPLETE",              //NOT_STARTED または COMPLETE
  "updatedAt": "2026-09-02T07:31:22Z",
  "updatedBy": "y.taro",
  "readOnlyFields": ["corporationName", "projectName"],
                                     //SQL由来。画面では読み取り専用で表示する
  "conditionalFields": [
    { "field": "batteryCapacity", "when": "hasBattery", "is": true }
                                     //hasBattery が true のときのみ batteryCapacity が必須
  ],
  "data": {                          //項目はページごとに異なる
    "assessingAdditionalityMethod": "初期投資回収年数による評価",
    "assessingAdditionalityMethodImg": "projectplan/PRJ001/additional-assessment-method/a1b2c3.png"
  }
}

//未入力のページでも HTTP 200 を返す。status が "NOT_STARTED"、data は空または初期値。


■ ページ保存

PUT /api/projectplan/{projectId}/forms/{formSlug}?methodology=2
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: application/json

Request Body (JSON): //ページの全項目を送る。部分更新はできない
{
  "assessingAdditionalityMethod": "初期投資回収年数による評価",
  "assessingAdditionalityMethodImg": "tmp/projectplan/PRJ001/a1b2c3.png"
}

Response - Success (HTTP 200)
{
  "statusCode": "OK",
  "formSlug": "additional-assessment-method",
  "displayName": "追加性の評価方法",
  "status": "COMPLETE",
  "updatedAt": "2026-09-02T07:31:22Z",
  "updatedBy": "y.taro",
  "data": { ... }                    //保存後の内容
}

//保存に成功すると、仮アップロードされたファイルが正式な保存先へ移動する。


■ 添付ファイルの仮アップロード

POST /api/projectplan/{projectId}/forms/{formSlug}/files?fieldName=assessingAdditionalityMethodImg
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: multipart/form-data

Request Parts:
  file      : アップロードするファイル（必須）
  fieldName : クエリパラメータ。ファイルを設定する項目名（必須）

Response - Success (HTTP 200)
{
  "statusCode": "OK",
  "s3Key": "tmp/projectplan/PRJ001/a1b2c3.png",
  "fileId": "a1b2c3",
  "originalName": "追加性評価.png"
}

//返却された s3Key を該当項目に設定してページを保存すると、正式な保存先へ移動する。
//保存されないまま放置された場合、ファイルは一時領域で失効する。
