API CONTRACT - OPERATOR COMPANY DETAIL

URL: GET /api/admin/companies/{companyId}
Example: GET /api/admin/companies/COMP00000001

Authorization: Bearer <operator_access_token>
Required Role: operator
Accept: application/json


PATH PARAMETERS

companyId
- Type: String
- Required: Yes
- Description: Business ID participating company.
- Example: COMP00000001
