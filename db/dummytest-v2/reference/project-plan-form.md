## ■HP公開について

- シート名の頭に【HP公開】と記載されているシートは、プロジェクト登録完了後、Ｊ－クレジット制度HPに公開します。

## ■様式のVer.について

- Ｊ－クレジット登録簿システムで利用可能な申請書のバージョンは、登録簿システムのトップページ（https://j-creditregistry.go.jp/toppage.html）にて確認してください。

## ■シート名・シート見出しの色について

- ・シート名の頭に【HP公開】と記載されているシート：プロジェクト登録完了後、Ｊ－クレジット制度HPに公開するシートです。

## ■様式のルールについて

| Excel input formatting meaning | Source row |
| --- | --- |
| 入力が必要なセル（自由記入） | 18 |
| 入力が必要なセル（プルダウンから選択） | 19 |
| 入力が不要なセル（自動入力） | 20 |
| 入力が任意のセル | 21 |
| 項目名など | 22 |

- セルの色の意味は以下の通りです。

- 文字は黒文字で入力をお願いいたします。その他の色での入力、セルの塗りつぶし等はしないでください。

- 計画変更の場合、変更箇所は赤字で入力をお願いいたします(様式の保護によって赤字にできない箇所は計画変更の場合でも赤字変更不要)。

- 登録簿システムではS-JIS(第一水準/ 第二水準)  、NEC 選定 IBM 拡張文字、NEC 特殊文字が入力可能です。

- それ以外の文字は登録簿システムへのアップロード時にエラーとなりますのでご注意ください。

- ↓入力不可の文字の例

- ・𠮷、倻、㟢（JIS第三水準）涁、𦥑、囍（JIS第四水準）など

## ■認証権限保有主体変更について

- プロジェクトの所有者（プロジェクトの認証申請が可能な口座）を変更する場合は、認証権限保有主体変更の手続きが必要となります。

- 変更手続きは、以下の通りお願いします。

- ・本ファイル内で非表示シートになっている「認証権限保有主体変更届」を再表示

- ・「認証権限保有主体変更届」の各項目を記入

- ・「登録申請書」シートの申請区分にて認証権限保有主体変更を選択

- ・Ｊ－クレジット登録簿システム（https://j-creditregistry.go.jp/toppage.html）にてお手続き

- ※手続き方法は操作マニュアル（https://j-creditregistry.go.jp/docs/japancredit_usermanual.pdf）の「3.8 認証権限保有主体変更を申請する（口座保有者、申請代行者向け）」を参照してください。

- なお、当該プロジェクトに関して、審査費用支援申請や検証申請が進行中の場合は、変更することができません。

## ■形式的な計画変更および登録情報の変更のみを申請する場合

- プロジェクト計画変更が生じた場合、登録簿システムから申請をお願いいたします。

- 形式的な計画変更および登録情報の変更のみを申請する場合、登録申請書シートの妥当性確認審査機関名は「環境省(ダミーの審査機関)」を選択してください。

- なお、形式的な変更もしくは登録情報の変更に該当しない場合は、審査機関による確認が必要です。

- プログラム型運営・管理者の担当者情報の変更の際は、必要に応じて、別途口座情報の担当者変更も行ってください。

## ■計画変更と認証申請を同時に申請する場合

- 登録簿システムでは、計画変更を処理してから、認証申請が処理されます。
