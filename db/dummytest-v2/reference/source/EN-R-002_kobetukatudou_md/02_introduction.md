## ■ 会員の削減活動開始日について

| Case | Rule / reminder |
| --- | --- |
| 【設備稼働開始後に入会を申し込む場合】 | 設備稼働開始日が入会申し込み日の2年前の日以降であれば、入会することができる。 |
| 【設備稼働開始前に入会を申し込む場合】 | 設備稼働開始日は入会申し込み日以降となるので、入会することができる。 ※入会後、設備の稼働が開始していることを確認する。 |
| 【入会不可のケース】 | 設備稼働開始日が入会申し込み日の2年前の日より前の場合、入会することができません。 |
